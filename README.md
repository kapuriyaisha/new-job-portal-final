# Job Portal Web Application

A full-stack Job Portal developed using React.js, Node.js, Express.js, and MongoDB. It connects job seekers and recruiters through an easy-to-use platform.

## Technologies Used
- Frontend: React.js, Material UI
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Integration: Groq AI
- Real-time Chat: CometChat

## Main Features

### User
- User Registration and Login
- Browse and Apply for Jobs
- Resume Analysis
- AI Job Matching
- Application Tracking
- Interview Management

### Recruiter
- Recruiter Dashboard
- Create and Manage Jobs
- Manage Received Applications
- Suitable Candidate
- Recruitment Email Generator
- Chat with Candidates
- Interview Scheduling
- Platform Feedback

### Admin
- Admin Dashboard
- Manage Users and Recruiters
- Manage Jobs and Categories
- Monitor Applications
- Manage Reported Content
- View Feedback

## Installation

1. Clone the repository.
2. Install frontend dependencies.
3. Install backend dependencies.
4. Configure environment variables.
5. Start the backend and frontend servers.
